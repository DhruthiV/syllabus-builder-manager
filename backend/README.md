# Syllabus Builder - Backend

This is the **backend** of the Syllabus Builder application, built using Node.js and Express.js. It provides REST APIs for managing syllabi, including creating, updating, finalizing, and storing them in a MongoDB database.

## Features

- **Create Syllabus**: Save new syllabi to the database.
- **Retrieve Syllabi**: Fetch all or specific syllabi.
- **Update Syllabus**: Modify details of a syllabus.
- **Finalize Syllabus**: Mark a syllabus as read-only.
- **Delete Syllabus**: Remove a syllabus from the database.

## Technology Stack

- **Node.js**: JavaScript runtime for server-side development.
- **Express.js**: Web framework for building REST APIs.
- **MongoDB**: NoSQL database for storing syllabi.
- **Mongoose**: ODM for MongoDB.
