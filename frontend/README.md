# Syllabus Builder - Frontend

This is the **frontend** of the Syllabus Builder application, built using React. It provides an interface for users to create, edit, finalize, and download syllabi.

## Features

- **Form-Based Syllabus Creation**: Fill in syllabus details through a user-friendly form.
- **Syllabus List**: View all saved syllabi.
- **Finalize Syllabus**: Mark a syllabus as complete, making it read-only.
- **PDF Download**: Generate and download syllabi as PDF files.

## Technology Stack

- **React**: Library for building user interfaces.
- **React Router v7 (Library Approach)**: For navigation and routing.
- **Axios**: For making API requests to the backend.
